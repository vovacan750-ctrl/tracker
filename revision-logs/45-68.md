- **45. - **54. Шаблонные строки, spread, rest:** добавлено явное предупреждение, что шаблонные строки не экранируют HTML; пример переведён на безопасную сборку DOM/textContent; исправлены вложенные шаблонные строки в исходнике.

- **56. async/await и fetch:** смягчено описание rejected Promise и `try/catch`; оставлена обязательная проверка `res.ok`.
- **57. Работа с JSON и внешними API:** секретный API-ключ убран из клиентского примера; добавлен server/serverless proxy, ограничения и ротация; уточнены значения HTTP 401/429 и `Retry-After`; добавлена оговорка о проверке документации версии на дату публикации.

- **59. Модули и npm:** сохранено различие frontend bundle и секретов через `.env`; уточнено, что `.env` не защищает секрет после попадания в браузер.
- **61. Библиотеки: Swiper, Lenis, AOS:** исправлено описание AOS, добавлены reduced-motion, фокус/клавиатура и проверка документации версии; включён `pauseOnMouseEnter`; исправлены опечатки и категоричные обещания.
- **62. Проект: интерактивный лендинг + корзина:** убрана формулировка о восьми обязательных функциях; критерии оставлены проектными и проверяемыми.

## Критические и major-проблемы, исправленные

- Небезопасная и неточная модель «объекты копируются по ссылке» заменена на корректную модель значений и ссылок.
- Spread больше не выдаётся за глубокую копию.
- Исправлен нерабочий `switch` с повторным `case` и необъявленными переменными.
- Исправлен fetch формы: HTTP-ошибки проверяются через `res.ok`, успех показывается только после подтверждённого ответа.
- Добавлены XSS-оговорки и безопасный DOM-подход для пользовательских/внешних данных.
- Секрет API исключён из клиентского кода; добавлен server-side proxy.
- Убрана устаревшая категоричная квота localStorage.
- Исправлены библиотечные рекомендации по reduced motion и паузе автопроигрывания.
- Добавлен заявленный переход к WordPress и исправлены базовые темы из аудита: версии только через проверку документации на дату публикации, classic/block, child themes, template hierarchy, loop/reset, ACF escaping и SEO/backup/security caveats.
- Добавлены юридические оговорки: материал не является юридической консультацией; нормы и требования к персональным данным/провайдерам нужно сверять с юристом и актуальным провайдером.
