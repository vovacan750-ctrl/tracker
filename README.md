# От нуля до профи — трекер обучения созданию сайтов

Интерактивная программа обучения: 11 глав, 124 урока, тест после каждого урока
и большой тест по каждой главе для закрепления.

Статический сайт без зависимостей — HTML, CSS, ванильный JavaScript.
Данные лежат в JSON, поэтому контент можно обновлять, не трогая код.

---

## Структура

```
.
├── index.html              # разметка страницы
├── assets/
│   ├── styles.css          # все стили
│   └── app.js              # логика: рендер, тесты, прогресс
├── data/
│   ├── lessons.json        # 124 урока + список глав
│   ├── quizzes.json        # тесты по урокам
│   └── block-quizzes.json  # большие тесты по главам
└── vercel.json             # конфигурация деплоя
```

## Возможности

- **124 урока** с теорией, терминологией, примерами из жизни, кодом и заданиями
- **Тест по уроку** — 8 вопросов, 4 варианта ответа, мгновенная проверка
- **Большой тест по главе** — 30–50 вопросов, открывается когда все уроки
  главы пройдены и тесты по ним сданы на 100%
- **Перемешивание** вариантов ответа при каждой попытке
- **Прогресс** сохраняется в браузере (localStorage)
- **Экспорт в CSV** для переноса между устройствами
- Фильтры по статусу и поиск по названию

## Обновление данных

Данные генерируются из исходных файлов скриптом `build-site.py`:

```
python build-site.py
```

Скрипт читает файлы уроков и тестов, нормализует HTML в блоках кода
и записывает результат в `data/`.

## Локальный запуск

Сайт статический, но данные грузятся через fetch, поэтому нужен любой
локальный сервер (открытие index.html двойным щелчком не заработает):

```
python -m http.server 8000
```

Затем откройте http://localhost:8000

## Деплой на Vercel

1. Залейте репозиторий на GitHub
2. На [vercel.com](https://vercel.com) выберите Add New → Project
3. Импортируйте репозиторий
4. Framework Preset: Other, Build Command — пусто, Output Directory — пусто
5. Deploy

Каждый push в main-ветку будет автоматически пересобирать сайт.
